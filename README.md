### GitHub User Activity

A lightweight command-line interface (CLI) tool to fetch and display the recent public activity of any GitHub user.

---

#### Prerequisites

- **Node.js**: `v22.18.0` or newer (uses native TypeScript execution support)

---

#### Usage

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/BlessedOneKobo/github-activity.git](https://github.com/BlessedOneKobo/github-activity.git)
   cd github-activity
   ```

2. **Run the code:**
   ```bash
   node index.ts username
   ```
